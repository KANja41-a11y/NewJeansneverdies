# NewJeans Never Dies

Gallery NewJeans tema Elegant + Cute.  
Siap langsung upload ke GitHub Pages.

## Fitur
- Members
- My Bias (member favorit)
- Group Photos
- Albums
- Lagu Ditto (Play/Pause)
- Kursor kelinci 🐰

## Upload ke GitHub Pages
1. Extract zip
2. Buat repo baru di GitHub (Public)
3. Upload semua file & folder
4. Settings → Pages → Deploy from branch `main` → `/ (root)`
5. Selesai
